# Rock Paper Scissors Game

> A Python-based command-line game demonstrating control flow, user interaction, and game logic implementation.

## Features
- Play against computer with random choices
- Input validation for user selections
- Option to abort game anytime
- Displays clear win/lose/tie results

## Tech Stack
- Python
- random module

---

## How It Works
The user selects rock, paper, or scissors, and the computer randomly generates a choice. The program compares both and determines the result based on standard game rules.
